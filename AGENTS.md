# AGENTS.md

Guide for AI agents working in this repo.

## Purpose

Talks on European digital topics for [DI.DAY](https://di.day), as HTML slide decks that run
offline via double-click and get passed on to others. Talks: EUDI Wallet/d-you, digital euro,
Fediverse. `lipsum` is the sample deck showing every slide layout.

## Language

- Slide content (`data/<talk>/slides/`, `deck.toml` texts, speaker notes) and on-screen labels: **German**.
- Research notes in `data/<talk>/` are slide material and stay German.
- Everything else is **English**: README, AGENTS.md, code comments, config comments, commit messages.

## Layout

- `data/<talk>/deck.toml`: title slide data, timer target and slide order (`slides = [...]`).
- `data/<talk>/slides/<name>.md`: one slide per file, named by content (no numbers). Files not
  listed in `deck.toml` are skipped with a warning. Next to `slides/`: research notes and `img/`.
- `src/`: shared code and design (`build.js`, `deck.js`, `style.css`, font, `vendor/` with marked, smol-toml and qrcode-generator).
- `<talk>.index.html`: generated by `node src/build.js [talk]`. Never edit by hand, but commit it.
- Format of `deck.toml` and slide files (header, layouts, `Note:`): comment at the top of `src/build.js`.

## Technical rules

- Must work over `file://`: no ES modules, no `fetch`, no CDN. Everything lives in the repo.
- No npm and no build tool besides `node src/build.js`. Ask before adding any dependency.
- Sober design: Atkinson Hyperlegible, light background. Default theme `eu` (EU blue `#003399`,
  politically neutral). Optional themes `gruene` and `did` (`src/<theme>.style.css`, `theme` in
  `deck.toml`, Shift+E/G/D live) reuse only the public brand colors: never their logos, sunflower
  or typefaces. Text colors must keep at least 4.5:1 contrast; light brand colors only for bars.
- Criticism and response (`layout: procon`) always get equal visual weight.
- Third-party images only with cleared rights; credit via `credit:`, license file next to the image.

## Content

- Accuracy above everything. Only sourced claims, every slide has `source:`. Prefer primary
  sources; media coverage only in the press section of a talk.
- Sober tone, no advertising or propaganda, including for the host.
- Never fill in numbers, dates or quotes from memory: verify and cite them.

## Workflow

- **Never commit, amend or push without the user's explicit permission for that change.**
  Finish the work, show what changed, propose the commit message(s), then wait for an OK.
- Small commits using Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:` …).
- Git hooks run via `prek` (`prek.toml`). Run `prek run --all-files` before larger commits.
- Agent hooks live in `.agents/hooks/` (linked for Claude as `.claude/hooks`).
- No codespell or other English spell fixer: it corrupts German text.
- Do not delete files with `rm`; use `git rm` for tracked files, otherwise ask the user.
